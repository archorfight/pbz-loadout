Four Difficulty Modes, One Question: Which One Are You?

Wayfarer, Pathbreaker, Hellwalker, and the permadeath run called Sixty-Six Days.

Quick answer: Phantom Blade Zero has four difficulty modes. Pick Wayfarer for story, Pathbreaker as the standard challenge, Hellwalker for adaptive enemy pressure — and Sixty-Six Days only if you accept permadeath. Exact damage multipliers per mode are not public yet.

The four modes OFFICIAL

ModeDesigned forKey rule
WayfarerStory-focused players — "a gentler path through the Wulin"Easier combat, full narrative
PathbreakerThe standard intended challengeBalanced combat and story
HellwalkerAction-game veteransAdaptive enemy pressure, demanding parry/deflect play
Sixty-Six DaysPermadeath challengersPermanent death — "not for the faint of heart"

Which should you pick?

If you're here for the Kung-Fu Punk world and Soul's revenge story: Wayfarer. If you've played Soulslclike/character-action games before: start Pathbreaker — the Sha-Chi parry system is the game's heart and lower difficulties mute it. Hellwalker is for second runs. Sixty-Six Days changes the game into a survival run — one life, and your weapon upgrades decisions get real weight.

Unknowns POST-LAUNCH

Per-mode damage taken/dealt multipliers, whether difficulty can be changed mid-run, and whether Sixty-Six Days has unique rewards — all verifiable only after the October 29 launch. This page updates with measured values then.
